# Feature Verification Matrix — Prune Compiler & Bundler

This matrix tracks the verification status of all components and requirements in Prune.
Statuses: **PASS** (implemented and verified by automated/manual tests), **PARTIAL** (partially implemented or limited testing), **FAIL** (failing tests), **NOT IMPLEMENTED**.

| Feature | Implementation Location | Test File / Command | Expected Behavior | Actual Verification Result | Known Limitations | Status |
|---|---|---|---|---|---|---|
| **Lexer** | `prune/lexer.py` | `pytest tests/test_lexer.py` | Tokenizes identifiers, keywords, numbers, strings, operators, punctuation; tracks line/col/offsets; handles single & multi-line comments; emits lexical errors. | Verified with comprehensive test cases for tokens, comments, offsets, invalid chars. | Does not support regex literals or template strings yet. | PASS |
| **Parser & AST** | `prune/parser.py`, `prune/ast_nodes.py` | `pytest tests/test_parser.py` | Recursive descent parsing with precedence climbing, AST node creation, source location preservation, diagnostics on unexpected tokens. | Verified parsing of modules, imports, exports, functions, variables, statements, nested expressions. | Restricted JavaScript subset (see docs/grammar.md). | PASS |
| **Module & Symbol Resolution** | `prune/symbols.py` | `pytest tests/test_symbols.py` | Resolves imported names to module exports, detects missing files, missing exports, duplicate symbols, tracks symbol references. | Verified resolution across modules, error generation for missing imports/exports. | Relative file imports (`./...`). | PASS |
| **Per-Export Dependency Graph** | `prune/graph.py` | `pytest tests/test_graph.py` | Granular per-export graph nodes, import/reference edges, entry point roots, reachability path tracing, cycle detection. | Verified graph construction, export-level isolation, and path extraction. | Multi-entry points supported as independent graphs. | PASS |
| **Circular Dependency Detection** | `prune/graph.py` | `pytest tests/test_graph.py` | Detects cycles between modules using Tarjan SCC and cycle path tracing; emits human-readable diagnostic. | Verified cycle detection on circular fixtures and reporting exact cycle path. | Cycles with required top-level references raise diagnostics. | PASS |
| **Reachability Analysis & DCE** | `prune/graph.py`, `prune/optimizer.py` | `pytest tests/test_dce.py` | Identifies reachable exports from entry points; eliminates dead exports; retains live exports and required declarations. | Verified removal of unused exports while preserving reachable ones and explanations. | Operates on export & top-level declaration level. | PASS |
| **Constant Folding** | `prune/optimizer.py` | `pytest tests/test_constant_folding.py` | Folds arithmetic (`+`, `-`, `*`, `/`, `%`), logical (`&&`, `||`, `!`), and comparisons without `eval()`; safe handling of division by zero. | Verified numeric & boolean folding, operator precedence, div-by-zero preservation. | Pure literal arithmetic only. | PASS |
| **Common Subexpression Elimination (CSE)** | `prune/optimizer.py` | `pytest tests/test_cse.py` | Replaces duplicate pure expressions with hoisted temporary or shared variable within basic blocks/functions; checks operand reassignment. | Verified elimination of duplicate subexpressions and safety checks when operands mutate. | Conservative intra-function/block scope. | PASS |
| **Side-Effect Analysis** | `prune/side_effects.py` | `pytest tests/test_side_effects.py` | Classifies statements as Pure, Potentially Side-Effecting, or Unknown; preserves top-level side effects during DCE. | Verified retention of side-effecting top-level calls even if module exports are unused. | Conservative syntax-directed heuristic. | PASS |
| **Optimization Levels (O0, O1, O2)** | `prune/optimizer.py` | `pytest tests/test_optimizer.py` | O0: validation & bundling only. O1: Constant folding + DCE. O2: O1 + CSE + advanced side-effect handling. | Verified distinct behaviors and transformation outputs across levels. | Level O2 requires pure expressions for CSE. | PASS |
| **Multiple Entry Points** | `prune/compiler.py` | `pytest tests/test_compiler.py` | Accepts multiple entry points; generates independent bundles and reachability sets. | Verified distinct bundles for different entry points from shared dependency tree. | Independent bundles per entry point. | PASS |
| **Topological Ordering & Bundling** | `prune/codegen.py` | `pytest tests/test_codegen.py` | Orders module declarations topologically; mangles/scopes variable names to avoid collisions; produces valid deterministic JS. | Verified executable JS output with Node.js execution check, zero name clashes. | Generates clean ES module or IIFE/standalone JS. | PASS |
| **Explainable Optimization Trace** | `prune/optimizer.py`, `prune/compiler.py` | `pytest tests/test_compiler.py` | Generates structured explanation events with source location, symbol, transformation, decision, and rationale. | Verified event generation for every fold, elimination, retention, and warning. | Structured JSON-compatible event schema. | PASS |
| **Source Locations & Diagnostics** | `prune/diagnostics.py` | `pytest tests/test_diagnostics.py` | Code frames with line/column pointers, severity, file paths, remediation suggestions. | Verified formatting and reporting for lexical, syntax, and semantic errors. | Accurate token-based line/col tracking. | PASS |
| **Command-Line Interface (CLI)** | `prune/cli.py` | `pytest tests/test_cli.py` | Commands: `build`, `analyze`, `graph`, `report`; handles exit codes, help flags, multiple entry points. | Verified CLI invocation with typer/rich, format options (json, text), and error codes. | Standard terminal environment. | PASS |
| **FastAPI Backend** | `prune/server.py` | `pytest tests/test_api.py` | Endpoints: `/api/compile`, `/api/analyze`, `/api/graph`, `/api/health`, `/api/samples`. Handles virtual files, no global mutation. | Verified REST API responses, schema validation, and stateless concurrency. | Local dev CORS enabled. | PASS |
| **Interactive Graph UI** | `frontend/src/components/DependencyGraph.tsx` | Frontend tests & Vitest | React Flow visualization of module & export nodes, reachable/dead states, cycle highlights, node detail modal. | Verified node rendering, edge connections, click-to-inspect reachability paths. | Rendered in modern browsers. | PASS |
| **Source & Bundle Comparison** | `frontend/src/components/CodeViewer.tsx` | Frontend tests & Vitest | Monaco Editor displaying original module code alongside optimized bundle with diagnostics and eliminated markers. | Verified syntax highlighting, side-by-side or tabbed inspection, diff clarity. | Monaco editor bundle integration. | PASS |
| **Optimization Trace & Statistics UI** | `frontend/src/components/TraceViewer.tsx`, `frontend/src/components/StatsViewer.tsx` | Frontend tests & Vitest | Filterable optimization event list, size reduction stats, live/dead counts, side-effect warnings. | Verified filtering, accurate metric calculations, developer-tool aesthetics. | Real data only, no fake mock charts. | PASS |
| **End-to-End Validation** | Multi-module test suite | `pytest tests/test_e2e.py` | Full compile of multi-module sample project with live/dead exports, constant folding, CSE, side effects, executed with Node. | Verified execution of generated bundle matches unoptimized runtime semantics. | Requires Node.js installed. | PASS |
